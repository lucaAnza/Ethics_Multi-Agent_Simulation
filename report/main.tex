\begin{abstract}
This project investigates ethical decision-making in autonomous driving
through an interactive simulation in which a vehicle must decide whether
to remain in its current lane or change lane when facing unavoidable
accidents.

Different ethical frameworks, including Utilitarianism, Kantian ethics
and Constant's approach, are implemented and compared.
Each framework can operate through a deterministic rule-based
implementation or through a Large Language Model (LLM) agent.

The simulator records decisions, casualties and framework-specific
metrics, allowing the behaviour and motivations of different ethical
agents to be analysed and compared. In addition to its experimental
purpose, the system is also designed as an educational tool, providing
an interactive graphical interface that helps users explore ethical
frameworks, observe their decision-making processes, and understand how
different moral principles can lead to different outcomes in the same
scenario.
\end{abstract}

\section{Introduction}

Autonomous systems are becoming increasingly present in areas such as transportation, healthcare, finance, public administration, and decision-support systems. As Artificial Intelligence is progressively integrated into contexts that directly affect people, its decisions can no longer be considered only from a technical perspective. Questions about responsibility, fairness, transparency, human values, and acceptable risk are becoming an essential part of AI design.

This explains why AI ethics is receiving growing attention both in research and in real-world applications. Modern AI systems are capable of making or supporting decisions at a scale and speed that would be impossible for humans, but this also means that their behaviour may have significant consequences. A system can be technically correct while still producing outcomes that are considered unfair, harmful, or ethically controversial.

Autonomous vehicles provide a particularly interesting environment for studying these problems. In some situations, every available action may produce undesirable consequences, forcing the system to choose between different forms of harm. Such decisions cannot always be reduced to a simple optimization problem, because different ethical theories may evaluate the same situation in very different ways.

This project develops an interactive autonomous-driving simulation designed to explore and compare different approaches to ethical decision-making. The vehicle is placed in controlled scenarios in which it must decide whether to remain in its current lane or change lane according to the ethical framework currently selected.

A further objective of the project is to investigate the difference between explicitly \textbf{programmed ethical behaviour} and \textbf{ethical reasoning} performed by a \textbf{Large Language Model}. Each framework can therefore be implemented both through deterministic code and through an LLM-based agent, allowing the same ethical principles to be evaluated using two different computational approaches.

The project is not intended only as an experimental platform for collecting data about ethical decisions. A significant part of the system is designed around an interactive graphical interface that allows users to visually explore the behaviour of the different ethical frameworks. Parameters, ethical rules, scenarios, decisions, and their consequences can be inspected directly through the simulation. This makes the application suitable both as an \textbf{experimental tool}, for comparing different configurations and analysing their results, and as an \textbf{educational tool}, helping users understand how different ethical theories can lead to different decisions when applied to the same practical dilemma.

\section{Implementation Technologies}

The system is implemented in Python 3.12.3 \cite{python3123} and is
structured to keep the simulation logic, graphical interface, ethical
frameworks, and LLM components as independent as possible.

\subsection{Simulation and User Interface}

The interactive environment is developed using the \texttt{Arcade}
framework (\texttt{arcade >= 3.3, < 4}).

Arcade is responsible for the real-time simulation loop, vehicle movement,
collision handling, graphical rendering, and user interaction. Its GUI
components are also used to build the configuration menus, framework
settings, simulation reports, and other interactive elements of the
application.

\subsection{LLM Integration}

LLM-based ethical agents are integrated through a dedicated abstraction
layer rather than being directly coupled to a specific provider.

The initial implementation uses Google's Gemini models. API keys and model
access are managed through Google AI Studio \cite{googleaistudio}, while
the interaction with Gemini from Python is implemented using the official
Google GenAI SDK, distributed through the \texttt{google-genai} package
\cite{googlegenai}.

The LLM receives the same decision context available to the deterministic
implementation and returns a structured action together with a textual
motivation.

\subsection{Environment}

The environment consists of a two-lane road containing different
entities such as pedestrians.

The autonomous vehicle moves automatically along the road until it
reaches the end of the scenario.

The only actions available to the ethical agent are:

\begin{itemize}
    \item \texttt{STAY}: remain in the current lane;
    \item \texttt{CHANGE\_LANE}: move to the adjacent lane.
\end{itemize}

The number of lane changes can be limited through the parameter
\texttt{max\_spostamenti}.


\subsection{Vehicle Perception}

The vehicle does not have complete knowledge of the environment.

It can only observe:

\begin{itemize}
    \item entities visible in the current lane;
    \item entities visible in the adjacent lane.
\end{itemize}

Two parameters control the decision process:

\begin{description}[leftmargin=3.5cm]
    \item[\texttt{vision\_distance}] maximum perception distance;
    \item[\texttt{decision\_distance}] distance at which an ethical
    decision is triggered.
\end{description}

Therefore, the ethical framework receives only the information that
would be available to the vehicle at decision time.


\subsection{Decision Context}

Every ethical agent receives the same structured context:

\begin{verbatim}
DecisionContext(
    vehicle_position,
    current_lane_entities,
    other_lane_entities,
    lane_changes_remaining
)
\end{verbatim}

This separation ensures that the perception system and the ethical
reasoning system remain independent.

\section{Ethical Frameworks}

Four main ethical approaches are considered.
This section briefly introduces each framework and its underlying idea.

The detailed implementation of each framework is described in Section~\ref{sec:rule_based_agent}.

% ------------------------------------------------
\subsection{Utilitarianism}

Utilitarianism is a consequentialist ethical theory according to which
the morality of an action depends primarily on its consequences.
The morally preferable action is the one that maximizes overall
well-being, taking into account the interests of all individuals affected.
Individual intentions are therefore secondary to the final outcome, and
moral decision-making can be interpreted as an optimisation problem.

The Utilitarian agent evaluates the consequences of the available
actions and selects the one associated with the lowest total ethical
cost.

Each category can be assigned a configurable malus:

\begin{center}
\begin{tabular}{lc}
\toprule
Category & Example Malus \\
\midrule
Child   & -30 \\
Adult   & -20 \\
Elderly & -10 \\
\bottomrule
\end{tabular}
\end{center}

For an action $a$, its cost can be expressed as:

\begin{equation}
C(a) = \sum_{i \in V(a)} w_i
\end{equation}

where $V(a)$ represents the victims associated with action $a$ and
$w_i$ is their configured ethical weight.

The action with the lowest cost is selected.

In case of equality, the vehicle remains in its current lane.


% ------------------------------------------------
\subsection{Kantian Framework}

Kantian ethics belongs to the deontological tradition and evaluates
actions according to moral duties rather than their consequences.
A central principle is universalizability: an action is morally acceptable
only if the maxim underlying it could be consistently adopted as a
universal rule. Moreover, individuals must be respected as ends in
themselves and should never be treated merely as instruments for
achieving another objective.

The Kantian implementation is based on configurable moral rules.

Examples of available rules include:

\begin{itemize}
    \item do not intentionally redirect harm;
    \item ignore personal categories;
    \item ignore numerical differences between lives;
    \item always protect children;
    \item do not increase harm;
\end{itemize}

Unlike Utilitarianism, the rules are organised according to a
\textbf{priority hierarchy}.

When multiple rules produce conflicting recommendations, the
higher-priority rule determines the decision.


% ------------------------------------------------
\subsection{Constant Framework}

Benjamin Constant criticised the rigidity of Kantian deontology,
particularly the idea that moral duties must hold without exception.
According to Constant, the application of a moral rule can depend on
the specific context in which an action takes place. Duties such as
truth-telling may therefore be defeasible when following them would
directly produce serious harm or injustice.

Constant is modelled using moral rules without an internal priority
hierarchy.

Each enabled rule has the same importance.

If the rules agree, their recommendation determines the action.
If they produce conflicting recommendations, a
\textbf{moral conflict} is detected.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\linewidth]{img/conflict_solver.png}
    \caption{Constant framework pipeline}
    \label{fig:conflict_solver}
\end{figure}

The current implementation resolves this conflict through a secondary
Utilitarian evaluation. However, the conflict-resolution strategy is
configurable and can be adapted or replaced with different approaches,
allowing alternative ethical criteria to be introduced without modifying
the overall framework structure.

% ------------------------------------------------
\subsection{Virtue Ethics}

The Virtue Ethics framework is available exclusively when the system
operates in \textbf{LLM mode}.

Unlike the other frameworks, it is not based on predefined numerical
weights or an explicit set of deterministic moral rules. Instead, the
language model is instructed to reason as a virtuous moral agent and to
select the action that best reflects virtuous character and practical
wisdom.

This approach is inspired by \textbf{Aristotelian} virtue ethics, according to
which moral action is not determined solely by fixed rules or by the
consequences of an action, but by the exercise of virtues and
\textit{practical wisdom} (\textit{phronesis}) in the specific
circumstances of a decision \cite{aristotle2009nicomachean}.

In the simulation, the LLM therefore evaluates the scenario by
considering qualities associated with a virtuous agent, such as
prudence, justice, courage, and temperance. The model is asked to
determine how a virtuous autonomous vehicle should behave in the given
situation and to return the action that is most consistent with these
principles.

\section{Rule-Based and LLM Agents}

Each framework provides two implementations:

\begin{itemize}
    \item \textbf{Code}: deterministic algorithmic implementation;
    \item \textbf{LLM-Agent}: decision generated by a Large Language Model.
\end{itemize}

For example:

\begin{verbatim}
Utilitarianism (code)
Utilitarianism (llm-agent)

Kant (code)
Kant (llm-agent)

...
\end{verbatim}

\subsection{Rule-Based Agent} \label{sec:rule_based_agent}

The rule-based agent implements the ethical frameworks directly in code
and therefore produces decisions synchronously and deterministically.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.4\textwidth]{img/determistic_agent_flow.png}
    \caption{Decision flow of the deterministic rule-based agent.}
    \label{fig:deterministic-agent-flow}
\end{figure}

During the \texttt{DRIVING} phase, the simulation continuously evaluates
the environment. When an unhandled incident in the current lane reaches
the configured decision distance, the simulator constructs an immutable
\texttt{DecisionContext}. The context contains the vehicle position, the
entities visible in the current and adjacent lanes, and the number of
remaining lane changes.

The context is then passed to the \texttt{CodeDecisionEngine}, which
delegates the decision to the currently selected ethical framework.
The deterministic implementation differs according to the framework:

\begin{itemize}
    \item \textbf{Utilitarianism}: the cost associated with the visible
    entities in each lane is computed using the configured entity values.
    The lane with the lower casualty cost is selected. In case of equal
    costs, the vehicle remains in its current lane.
    \begin{figure}[H]
        \centering
        \includegraphics[width=0.7\linewidth]{img/code_lower.png}
        \caption{Part of utilitarianism engine implementation}
        \label{fig:code_utilitarianism}
    \end{figure}

    \item \textbf{Kant}: enabled moral rules are evaluated according to
    their configured priority. The first applicable rule determines the
    action. If no enabled rule resolves the situation, the default action
    is \texttt{STAY}.
    \begin{figure}[H]
        \centering
        \includegraphics[width=0.7\linewidth]{img/code_rule.png}
        \caption{Example of Kant rule solving}
        \label{fig:code_kant}
    \end{figure}

    \item \textbf{Constant}: all enabled moral rules are evaluated at the
    same priority level. If all applicable rules agree, their common action
    is selected. If they conflict, the conflict is resolved through the
    configured utilitarian evaluation. If no rule applies, the default
    action is \texttt{STAY}.
\end{itemize}





The framework returns an \texttt{EthicalDecision} containing the
recommended action, its explanation, and framework-specific metadata.
The possible actions are

\begin{center}
\texttt{STAY}
\qquad\text{or}\qquad
\texttt{CHANGE\_LANE}.
\end{center}

The recommended action is subsequently validated by the simulation
engine. In particular, a \texttt{CHANGE\_LANE} recommendation is applied
only if the world can actually start the lane-change maneuver. If the
maneuver is unavailable, for example because the maximum number of lane
changes has already been reached, the applied action becomes
\texttt{STAY}.

The distinction between the \emph{recommended decision} and the
\emph{applied decision} is preserved in the simulation event and allows
the evaluation phase to distinguish ethical recommendations from
execution constraints.

Figure~\ref{fig:deterministic-agent-flow} summarizes the complete
deterministic decision process.


\subsection{LLM Agent}

The LLM-based agent follows a decision process similar to the one shown in Figure~\ref{fig:deterministic-agent-flow}, but uses a different decision engine, namely the \texttt{LLMDecisionEngine}, to obtain the ethical decision from the language model.


\subsubsection{Prompt}

The LLM prompt is constructed from four components:

\begin{equation}
P =
P_{\text{system}}
+
P_{\text{framework}}
+
P_{\text{user}}
+
P_{\text{context}}
\end{equation}

The system and framework prompts are stored in configuration files and
cannot be modified through the interface.

The user can instead provide additional natural-language instructions
through the framework settings.


\subsubsection{Asynchronous Decisions}

LLM requests must not block the Arcade rendering loop.

When an LLM decision is required, the simulation transitions through:

\begin{center}
\texttt{DRIVING}
$\rightarrow$
\texttt{WAITING\_FOR\_LLM}
$\rightarrow$
\texttt{EXECUTING\_DECISION}
$\rightarrow$
\texttt{DRIVING}
\end{center}

The simulation time is paused while waiting for the response, while the
graphical interface remains responsive.

\section{Decision History and Explainability}

Every decision is stored together with its context and explanation.

For example:

\begin{verbatim}
{
    "decision_id": 3,
    "position_x": 1250,
    "action": "CHANGE_LANE",
    "current_lane": "...",
    "other_lane": "...",
    "reason": "..."
}
\end{verbatim}

In the Simulation section is possible to see the user interface for this kind of data [\ref{fig:decision_history}]
For LLM agents, additional information are recorded:

\begin{itemize}
    \item model used;
    \item response latency;
    \item whether a fallback was required.
\end{itemize}

This allows the final action to be analysed together with the reasoning
that produced it.

\section{Experimental Evaluation}

\subsection{Experimental Setup}

The number of simulation runs depends on the type of experiment being performed.

For experiments comparing the \textbf{Code} and \textbf{LLM-Agent} implementations, a maximum of \textbf{100 paired simulations} is executed. This limitation is mainly due to the API usage constraints and the significantly higher execution time associated with LLM requests.

The LLM-based experiments use Google's \texttt{gemini-3.5-flash-lite} model \cite{gemini35flashlite}. The model was selected because it is designed for low-latency and high-throughput workloads, making it suitable for repeated decision requests within the simulation.

In contrast, experiments involving only deterministic \textbf{Code agents} are executed for up to \textbf{100,000 simulations}. Since these agents operate locally and do not require external API calls, they can be evaluated much more efficiently and on a substantially larger number of scenarios.

When Code and LLM implementations are compared, the same scenarios, initial conditions, and random seeds are used for both agents.

% ------------------------------------------------
\subsection{Internal Consistency: Code vs LLM}

The first group of experiments investigates whether the deterministic
implementation and the LLM-based implementation of the same ethical
framework behave consistently.

\subsubsection{Utilitarianism}

The following experiments are performed:

\begin{enumerate}

    \item \textbf{Strongly protected category -- random scenarios}

    A very high ethical malus is assigned to one specific category,
    for example children, while lower values are assigned to the other
    categories.

    The experiment evaluates whether both implementations consistently
    protect the strongly weighted category.

    For the strongly protected category experiment, the following Utilitarian
    weights are used:
    
    \begin{center}
    \begin{tabular}{lc}
    \toprule
    Category & Ethical weight \\
    \midrule
    Children & 85 \\
    Adults   & 35 \\
    Elderly  & 20 \\
    \bottomrule
    \end{tabular}
    \end{center}

    \textit{Research question:}
    Does the LLM correctly reproduce the strong preference encoded by
    the Utilitarian weights?


    \item \textbf{Equal weights -- random scenarios}

    All categories are assigned the same ethical weight.

    In this configuration, the Utilitarian decision should mainly depend
    on the total number of casualties rather than on their category.

    \textit{Research question:}
    Do the deterministic and LLM implementations converge towards similar
    decisions when all human lives have the same configured weight?


    \item \textbf{Different weight configurations -- random scenarios}

    Multiple configurations of category weights are tested using the same
    random scenarios for both implementations.

    \textit{Research question:}
    Does the LLM adapt consistently when the ethical priorities defined
    by the weights are changed?


    \item \textbf{Scenario where everyone can be saved}

    A controlled scenario is created in which a sequence of valid
    decisions allows the vehicle to complete the simulation without any
    casualties.

    \textit{Research question:}
    Are both implementations able to identify and follow the
    zero-casualty solution?

\end{enumerate}


\subsubsection{Kantian Ethics}

The following experiments are performed:

\begin{enumerate}

    \item \textbf{Random rule configurations}

    Different combinations of enabled rules and priority orders are
    generated and tested on identical scenarios.

    \textit{Research question:}
    Does the LLM reproduce the decisions of the deterministic Kantian
    implementation and correctly respect the configured rule hierarchy?


    \item \textbf{Scenario where everyone can be saved}

    A controlled scenario is used in which it is possible to avoid all
    casualties without violating the available actions.

    \textit{Research question:}
    Do both Kantian implementations identify the non-harmful solution
    when no real moral trade-off is necessary?

\end{enumerate}


\subsubsection{Constant's Approach}

The following experiments are performed:

\begin{enumerate}

    \item \textbf{Random rule configurations}

    Different sets of active rules are generated and tested using the
    same scenarios for both implementations.

    \textit{Research question:}
    How similar are the deterministic and LLM implementations when
    Constant's rules are configured in the same way?


    \item \textbf{Scenario where everyone can be saved}

    A controlled scenario is created in which all casualties can be
    avoided.

    \textit{Research question:}
    Do both implementations successfully identify the solution that
    avoids unnecessary harm?

\end{enumerate}


% ------------------------------------------------
\subsection{Framework Comparison}

The second group of experiments compares different ethical theories
directly.

All frameworks are evaluated using the same scenarios and random seeds,
so that the comparison focuses on differences generated by their ethical
decision strategies.


\subsubsection{Kant vs Constant -- Deterministic Implementations}

The deterministic implementations of Kant and Constant are executed on
the same set of scenarios.

The main difference between the two approaches lies in \textbf{conflict
resolution}: Kant uses a hierarchy of moral rules, while Constant allows
rules to remain at the same level and uses an additional conflict
resolution strategy when necessary.

The main research question is:

\begin{quote}
\textit{Does the greater flexibility of Constant's conflict-resolution
mechanism lead to fewer casualties than the hierarchical Kantian
approach?}
\end{quote}

\subsubsection{Comparison Between All Frameworks}

Utilitarianism, Kantian Ethics, Constant's approach and Virtue Ethics are
executed on the same scenarios using identical random seeds.

The objective is not to identify an objectively ``correct'' ethical
theory, but to compare the practical consequences produced by each
framework.

The main research question is:

\begin{quote}
\textit{How do different ethical frameworks compare when evaluated
according to common quantitative outcome metrics?}
\end{quote}

% ------------------------------------------------
\subsection{Evaluation Metrics}

The following metrics can be collected for each simulation and aggregated
across multiple runs.

\subsubsection{General Simulation Metrics}

\begin{itemize}

    \item \textbf{Total casualties}: total number of entities killed
    during the simulation.

    \item \textbf{Average casualties per simulation}: mean number of
    casualties across all runs.

    \item \textbf{Average lane changes}: mean number of lane changes across
    all simulations.

    \item \textbf{Average decision per simulation}: mean number of
    decision across all runs.

    \item \textbf{Casualties by general category}: number of casualties for each
    entity category (adult,...)

    \item \textbf{Casualties by specific category}: percentage of encountered
    entities belonging to a category that are killed.

    \item \textbf{Zero-casualty rate}: percentage of simulations completed
    without casualties.

    \item \textbf{Lane changes used}: number of lane changes performed
    during a simulation.

    \item \textbf{STAY / CHANGE\_LANE ratio}: distribution of the two
    possible actions selected by the agent.

    \item \textbf{Number of ethical decisions}: total number of decisions
    triggered during the simulation.

    \item \textbf{Framework-specific metrics}: additional values generated
    by the selected ethical framework, such as total Utilitarian malus,
    number of rule conflicts, or rules responsible for Kantian decisions.

\end{itemize}


\subsubsection{Code vs LLM Metrics}

For experiments comparing deterministic and LLM-based implementations,
additional metrics are considered:

\begin{itemize}

    \item \textbf{Decision agreement rate}: percentage of decision points
    in which Code and LLM select the same action.

    \item \textbf{Simulation outcome agreement}: percentage of paired
    simulations that end with the same total number of casualties.

    \item \textbf{Casualty difference}: difference in total casualties
    between Code and LLM for the same scenario.

    \item \textbf{Category-specific agreement}: similarity between the
    casualty distributions produced by the two implementations.

    \item \textbf{LLM response latency}: time required by the LLM to
    produce each decision.

\end{itemize}

These metrics allow the experiments to evaluate not only the final
number of casualties, but also the consistency of the decision process,
the behaviour of LLM agents, and the practical differences between the
ethical frameworks.
